Blocks appear in Streamline as Office Blocks (type 6) under this name, so they're easy to spot on the calendar and in reports.

How removal works

The Streamline API token can create reservations but has no cancel or modify method enabled. When a booking that caused a block is cancelled or moved, the block is marked Needs manual removal on the Blocks tab with its Streamline confirmation number. Delete it there, then mark it removed here.

Ask Streamline support to enable a cancel method on the token and this becomes automatic.
